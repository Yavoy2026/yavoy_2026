# Логотипы платёжных систем

Требование п.5 «Выполнение требований Банка к сайту» (АО «Октобанк», YAV-21):
на сайте должны быть размещены марки платёжных систем, которые принимаются к оплате.

Компонент `src/components/PaymentSystems.tsx` ждёт здесь файлы с точными именами:

| Файл             | Где взять официальный ассет |
|------------------|-----------------------------|
| `visa.svg`       | https://merchantsignage.visa.com/brand_guidelines |
| `mastercard.svg` | https://www.mastercard.com/brandcenter/en/brand-requirements/mastercard/name |
| `unionpay.svg`   | brand-центр UnionPay International |
| `uzcard.svg`     | uzcard.uz — раздел с фирменным стилем |
| `humo.svg`       | humocard.uz — раздел с фирменным стилем |

Пока файла нет, вместо марки выводится текстовая подпись: страница не ломается,
но требование банка формально не закрыто.

**Нельзя** рисовать марки самостоятельно или брать их со сторонних сайтов —
банк сверяет размещение с brand guidelines платёжных систем.

Список принимаемых систем должен совпадать с тем, что реально подключено
в договоре эквайринга: показывать марку системы, которой платить нельзя, — нарушение.
